# Atharva J - Portfolio (React + Vite + Tailwind + Framer Motion)

Local dev:
1. npm install
2. npm run dev

Build:
1. npm run build

Deploy (push dist to GitHub Pages using gh-pages - default pushes to gh-pages branch):
1. npm run deploy

Make sure the repo remote is: https://github.com/attharva-j/attharva-j.github.io.git

Resume:
The Resume buttons switch themselves on when `public/resume.pdf` exists at build
time. To publish a resume, add the PDF at that path and push (or restart
`npm run dev` locally). Without the file, the buttons show "Reach out via email
for requesting my resume".
